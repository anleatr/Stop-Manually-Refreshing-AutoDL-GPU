# 使用指南

## 用户配置

在「用户配置」打开专用浏览器，亲自完成 AutoDL 登录，再点「检查登录」。桌面版会在启动时核验保存的会话；通过核验后自动同步实例，并在后台运行 Edge。会话过期或需要人工验证时，再打开登录窗口处理。

余额来自自己的 AutoDL 开发者 Token。在「余额 Token 设置」中保存后查询，可选在本机加密记住。常规自动更新间隔为 10 分钟，手动刷新及提交前的余额校验可提前查询。

账号的实例列表支持选择已关机实例作为克隆源，点击后跳转到资源监测并填入源实例。

## 创建任务

「资源监测」支持新建实例和迁移克隆。选择命中资源后的行为、地区、型号、卡数及数据盘容量。新建任务需要选择官方基础镜像，克隆任务先选源实例，地区锁定为源实例所在地区。

官方报价、监测时长、余额保护、检查间隔和扫描范围集中在「高级设置」。发现资源后自动创建并开机的任务需要勾选费用授权，再点「创建任务」。选择「只通知」时停在提交之前。

克隆可以选择复制数据盘。换 GPU 型号后，需要确认源实例中的框架支持目标架构。数据盘复制状态需要单独核验。

## 任务队列

队列统一展示状态及日志，支持暂停、恢复、确认完成和删除。每次进入页面回到顶部，停留查看时保持滚动位置。

- 「已完成」要求人工确认，结束本地后续检查并解除对应任务的重复创建限制。
- 同资源冲突时，可查看原任务，或选择「人工确认后继续创建」。该操作保留原提交记录，确认原任务完成后再建立新任务，可能重复租用并增加费用。
- 「删除」从队列移除任务并停止其后续检查，本地历史提交依据仍保留。有未核对提交的任务应先核对或确认完成。
- 这些本地操作不会关闭或释放已创建的云端实例。

## 通知与退出

通知设置支持桌面提醒、AutoDL 微信和 HTTPS Webhook。关闭桌面主窗口会隐藏到托盘，监测继续；选择托盘菜单的「退出」才正常停止服务。保持电脑联网和唤醒。

网页运行模式通过 `npm start` 启动，关闭启动终端或运行 `npm run stop` 可正常停止。网页服务仅监听本机地址。

## 数据和安装

安装方式、开发命令和路径配置见 [README](../README.md)。运行资料与专用浏览器登录保存在同一个运行目录，不要共享。主动记住的凭据由当前 Windows 用户加密，换电脑或 Windows 用户后重新配置。

历史测试记录见 [TEST_REPORT.md](../TEST_REPORT.md)，当前维护流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。
